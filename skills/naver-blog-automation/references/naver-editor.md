# 네이버 스마트에디터 작업 메모

이 문서는 네이버 블로그에 직접 옮길 때만 읽는다. 화면과 메뉴는 바뀔 수 있으므로 현재 UI를 확인해 조작한다.

## 본문 붙여넣기

스마트에디터는 HTML 붙여넣기의 CSS, 레이아웃, 빈 문단, 외부 이미지 등을 정리한다. 문단 사이 여백이 중요한 글은 플레인 텍스트의 빈 줄(`\n\n`)로 본문 구조를 먼저 넣고, 에디터에서 강조를 다시 적용한다. HTML 붙여넣기는 굵게·링크가 일부 보존되지만 빈 줄이 사라질 수 있다.

이미지는 `<img>` 태그로 넣지 않는다. 사진 버튼으로 파일을 업로드하고 업로드 뒤 실제 표시를 확인한다. 제목은 본문과 분리해 제목 입력란에 넣는다.

## 글쓴이 형식 재현

`STYLE_BLOG.md`에 확인된 크기·색·줄간격·소제목 형식을 우선한다. 예시로 「AI 읽어주는 변리사」 편집본은 본문 나눔고딕 19px·검정·행간 1.8, PART 제목에 왼쪽 세로선 인용구, 핵심 구절에 선택적인 굵게+밑줄을 사용했다. 이는 다른 브랜드의 공통 규칙이 아니다.

자료의 원문 캡처는 해당 주장 가까이 두고, 출처와 정확한 쪽수·도표 번호를 이미지 캡션에 간결하게 적는다. 긴 URL은 캡션마다 반복하지 않고 글 끝에서 원문 링크를 확인할 수 있게 한다. 사진 아래와 본문에 같은 출처가 중복되지 않도록 점검한다.

## 저장 점검

화면의 처음·중간·끝을 확인해 누락된 문단, 깨진 줄바꿈, 잘못 들어간 사진, 비어 있는 캡션을 찾는다. 사용자 편집본이 이미 있다면 로컬의 오래된 원고를 다시 붙여넣지 않는다. 임시저장 완료 표시를 확인한 후 작성 화면을 사용자에게 남긴다.
