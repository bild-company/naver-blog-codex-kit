# Codex로 네이버 블로그 글 작성하기

이 저장소는 네이버 블로그 글의 **스타일·브랜드 설정 → 주제별 자료 수집 → 원문 캡처 → 초안 작성 → 사람의 수정 → 스마트에디터 업로드**를 Codex로 시연하기 위한 수강생용 자료입니다. 수강생은 빈 프로젝트 폴더를 먼저 만들고 Codex에서 연 다음, 이 저장소의 파일을 **현재 프로젝트 폴더의 루트**에 내려받습니다. 내려받은 `AGENTS.md`가 작성 스킬을 안내합니다.

[자동화 개념도 열기](docs/naver-blog-automation.excalidraw) — Excalidraw에서 편집할 수 있는 파일입니다.

## 폴더 구성

| 위치 | 용도 |
|---|---|
| `skills/naver-blog-automation/SKILL.md` | 블로그 글 작성·수정·업로드 절차 |
| `STYLE_BLOG.md` | 실제 내 게시글 링크를 분석해 채울 작성 스타일 |
| `brand/BRAND.md` | 브랜드 설명, 독자, 톤, 공개 가능한 사실 |
| `brand/logo-placeholder.svg` | 공식 로고를 넣을 자리 표시 예시 |
| `AGENTS.md` | Codex가 이 프로젝트에서 읽을 작업 지침 |
| `docs/naver-blog-automation.excalidraw` | 강의용 자동화 개념도 |

`STYLE_BLOG.md`와 `brand/BRAND.md`에는 처음에 `작성 전 입력` 표시가 있습니다. 예시 문구를 실제 브랜드 사실로 오인하지 않도록 두 파일을 먼저 채웁니다. 공식 로고가 있으면 `brand/`에 추가하고 `BRAND.md`의 파일명을 고칩니다.

## 영상 시연 순서와 복사할 요청문

1. 컴퓨터에 빈 프로젝트 폴더를 하나 만들고, Codex 앱에서 **그 폴더를 프로젝트 폴더로 엽니다.** 폴더 이름은 자유롭게 정합니다.
2. **현재 프로젝트 폴더에 GitHub 자료 받기** — Codex에 아래 요청문을 보냅니다. 저장소 파일이 지금 연 폴더의 루트에 들어와야 합니다.

   ```text
   지금 Codex에서 열려 있는 빈 프로젝트 폴더에 아래 GitHub 저장소를 바로 내려받아줘.
   https://github.com/bild-company/naver-blog-codex-kit
   새 하위 폴더를 만들지 말고, 현재 폴더가 비어 있으면
   git clone https://github.com/bild-company/naver-blog-codex-kit.git . 명령으로 진행해줘.
   이미 파일이 있다면 덮어쓰지 말고 먼저 알려줘.
   완료 후 README.md, AGENTS.md, skills/naver-blog-automation/SKILL.md,
   STYLE_BLOG.md, brand/BRAND.md가 현재 프로젝트 폴더에 있는지 확인해줘.
   AGENTS.md와 SKILL.md를 읽고 다음 블로그 작업에 적용해줘.
   ```

   `AGENTS.md`, `STYLE_BLOG.md`, `brand/`, `skills/`가 같은 프로젝트 루트에 보여야 합니다. `naver-blog-codex-kit`이라는 하위 폴더를 다시 열 필요가 없는 구성입니다.
3. **소스 글 두 편으로 작성 스타일 만들기**

   > 아래 네이버 블로그 글 두 편을 읽고 `STYLE_BLOG.md`를 업데이트해줘. 두 글에 공통으로 나타나는 문체·구성·서식과 한 글에서만 보이는 선택을 구분하고, 각 판단의 근거 URL을 남겨줘. 원문을 길게 복사하지 마. 링크 1: [내 글 URL] / 링크 2: [내 글 URL]

   강의에서는 [참고 글 1](https://blog.naver.com/binaryho/224426503852)과 [참고 글 2](https://blog.naver.com/binaryho/224424158399)를 사용합니다. 수강생은 자신의 글 링크로 바꿉니다.

4. **브랜드 설명과 로고 넣기**

   > 내 브랜드 정보로 `brand/BRAND.md`를 채워줘. 브랜드명: [ ], 주요 독자: [ ], 제공하는 내용: [ ], 말투: [ ], 공개 연락처: [ ]. 첨부한 로고를 `brand/`에 넣고 파일명을 기록해줘. 확인되지 않은 경력이나 성과는 만들지 마.

5. **정한 주제로 자료 수집·원문 캡처·초안 작성** — 강의에서는 *Dental Monitoring v. Align* 판결을 시연합니다. 주제만 알려주고 Codex가 자료를 찾는 과정을 화면에 보여줍니다.

   ```text
   이번 글의 주제는 Dental Monitoring v. Align 판결과 AI 특허의 §101 쟁점이야.
   STYLE_BLOG.md, brand/BRAND.md와 네이버 작성 스킬을 적용해줘.
   공식 판결문 PDF와 Sterne Kessler 뉴스레터를 찾아 URL·날짜·작성자를 확인하고
   content/dental-monitoring-align/sources/에 원문과 출처 정보를 저장해줘.
   관련 판결문 페이지를 실제 PDF에서 PNG로 캡처해
   content/dental-monitoring-align/assets/에 저장해줘.
   판결문 문구를 이미지로 새로 생성하지 마. 해당 주장 바로 아래에 이미지를 넣고
   캡션에 사건명·판결일·정확한 쪽수를 적어줘.
   판결의 판단, 로펌 해설, 검토할 실무적 제안을 구분해
   content/dental-monitoring-align/blog_ko.md에 초안을 작성해줘.
   ```

   다른 주제도 같은 방식으로 진행하되 그 주제에 맞는 1차 자료와 해설을 찾습니다. 실제로 확인하지 못한 자료를 읽은 것처럼 쓰지 않습니다.

6. **Codex에서 초안 수정**

   > 내가 고친 초안을 기준으로 [수정할 부분]을 다듬어줘. 직접 고친 문장과 주장, 이미지 순서는 유지하고 변경한 부분을 알려줘.

7. **네이버 스마트에디터에 자동 업로드하고 확인**

   > 내가 수정한 최신 Markdown 초안을 Codex 인앱 브라우저의 네이버 스마트에디터에 옮겨줘. 제목과 본문을 분리하고 실제 이미지 파일을 표시한 위치에 업로드해줘. 원문 캡처의 출처·쪽수는 해당 이미지 캡션에 넣어줘. 처음·중간·끝의 문단과 이미지 순서를 확인한 뒤 임시저장하고, 저장 완료 표시를 확인해줘. 공개 발행은 하지 마.

8. **최종 수정에서 스타일 갱신**

   > 내가 고친 최종 글과 `STYLE_BLOG.md`를 비교해 반복해서 적용할 만한 문체·서식만 근거와 함께 파일에 반영해줘. 이번 글에만 필요한 선택은 별도로 표시해줘. 작업 절차 자체를 바꿔야 할 부분이 있으면 `SKILL.md` 수정안을 알려줘.

네이버 로그인은 본인이 인앱 브라우저에서 마칩니다. **임시저장과 공개 발행은 다른 작업**입니다. 공개를 원할 때는 발행을 별도로 요청합니다. 에디터 UI가 바뀌면 현재 화면을 기준으로 조작합니다.

## 배포 전 확인

- `brand/`에는 공개해도 되는 설명과 로고만 넣습니다.
- 로그인 정보, 인증 코드, 고객 자료, 공개하지 않을 초안은 저장소에 올리지 않습니다.
- 출처 글의 문체를 참고하되 원문을 대량 복제하지 않습니다.
